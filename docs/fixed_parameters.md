# 固定搜索空间与训练学习参数

当前版本将“预先声明的算法范围”和“训练过程学习出的模型参数”分开保存。

## 预先声明的算法范围

| 参数 | 固定值 | 作用 |
|---|---|---|
| `SEED` | `0` | 固定 VIP 掩码扰动与 GPR 训练过程 |
| `FFT_CUTOFF` | `0.02` | 去除最低 2% 频率分量，抑制缓慢背景 |
| `VIP_THRESHOLD` | `1.0` | PLS-VIP 波长筛选阈值 |
| `VIP_COMPONENTS` | `20` | 计算 VIP 的最大 PLS 分量数 |
| `GPR_RESTARTS` | `2` | GPR 核超参数优化重启次数 |
| `MASK_AGGREGATES` | `5` | VIP 掩码确定性扰动集成次数 |
| `RAW_POINTS` | `512` | 几何残差分支的重采样长度 |
| `ALL_PAIRS` | `(5,2)` 至 `(17,8)` | 7 组 SG 窗口与局部邻域尺度 |
| `WEIGHT_PENALTIES` | `0` 至 `0.1` 的 5 个候选 | 融合权重 L2 正则搜索范围 |
| `GEOMETRY_CANDIDATES` | `3, 5, 7, 10` | 几何残差 PCA 维数候选 |
| `CORRECTION_CANDIDATES` | `0, 0.35, 0.70, 1.0` | 残差修正比例候选 |
| `SELECTION_SEED` | `20260827` | 固定训练集选择划分 |

四个局部发射波段也在 `code/model_core.py` 中预先声明，用于提取连续谱残差和 Haar 多尺度特征。

## 训练过程学习的内容

以下内容不是手工填写的测试预测，而是由训练集折外预测、内层验证或全训练拟合产生：

- 每个尺度的五核融合权重；
- 七个尺度之间的融合权重；
- 各 GPR 核的拟合参数和每折 VIP 掩码；
- 煤种内校准斜率与截距；
- C_mad3 异常训练批次；
- 几何残差维数，当前训练结果为 `10`；
- 残差修正比例，当前训练结果为 `0.35`；
- 训练折外残差与复现所需的训练数据快照信息。

训练结果写入 `user_data/model_data/model_weights.npz`，详细审计信息写入 `user_data/model_data/model_config.json`。
