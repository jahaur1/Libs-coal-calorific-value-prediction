# Field LIBS Coal Calorific Value Prediction

基于现场 LIBS 光谱的煤炭弹筒发热量预测方案，记录完整建模过程、训练与推理代码、固化模型以及比赛平台返回成绩。项目最优官方 RMSE 为 **140.71316**。

## 项目背景

煤炭发热量是煤质评价、燃料定价和燃烧优化的重要指标。传统弹筒发热量需要在实验室内完成取样、混合缩分和化验，检测周期较长。激光诱导击穿光谱（Laser-Induced Breakdown Spectroscopy，LIBS）能够在煤场皮带上快速采集煤流的元素光谱，为发热量在线预测提供基础。

本项目对应“基于现场 LIBS 光谱的煤炭弹筒发热量预测挑战赛”。任务是根据煤场现场采集的 LIBS 光谱以及训练阶段提供的煤质化验信息，预测每个批次的实验室弹筒发热量。训练集包含多个历史月份，测试集为完整的未来月份，因此不仅需要建立光谱到发热量的映射，还需要处理真实工业数据中的时间变化。

### 核心难点

1. **多对一弱对齐**：同一批次包含十至二十余条瞬态光谱，却只对应一个混合煤样的宏观化验标签，单条光谱与标签并非严格对应。
2. **高维小样本**：单条光谱包含大量波长通道，而有效批次数量有限，模型容易出现高方差和过拟合。
3. **现场采集噪声**：煤流状态、激光击穿位置、基线漂移和散射差异会引入明显的批次内波动。
4. **跨时间分布偏移**：训练集和测试集按月份切分，未来月份的光谱分布可能与历史数据不同。
5. **煤种异质性**：不同煤种的发热量范围、光谱响应和校准关系存在系统差异。

## 方法概述

模型以批次为基本预测单位，先聚合同一批次的多条 LIBS 光谱，再构建多个光谱尺度和 GPR 核的互补预测。基础输出经过煤种内稳健校准后，引入 LVSE、Haar 局部能量和 PCA 几何表示估计折外残差，并通过样本级可靠性门控控制修正幅度。

### 整体架构

```text
同批次 LIBS 光谱（单条 7305 维，多条/批次）
   │
   ├─ 批次级光谱聚合
   │    └── 多条瞬态光谱求均值 → 批次级建模样本
   │
   ├─ 光谱预处理
   │    ├── FFT 高通去除低频背景
   │    ├── Savitzky–Golay 一阶导数
   │    └── MSC 多元散射校正
   │
   ├─ Stage 1：多尺度、多核 GPR 基础模型
   │    ├── 三组（SG 窗口，局部邻域半径）
   │    │    ├──（13，6）
   │    │    ├──（11，5）
   │    │    └──（15，7）
   │    ├── 折内 PLS-VIP 波长选择
   │    ├── 五类回归核
   │    │    ├── RBF
   │    │    ├── Matérn 1.5
   │    │    ├── Matérn 2.5
   │    │    ├── Rational Quadratic
   │    │    └── Dot Product
   │    └── 核融合 + 尺度融合 → 基础 OOF / 测试预测
   │
   ├─ Stage 2：煤种内稳健校准
   │    ├── C_mad3 折外残差异常筛选
   │    └── 煤种内留一法线性校准
   │
   ├─ Stage 3：光谱几何残差修正
   │    ├── 光谱统一重采样至 512 点
   │    ├── LVSE 局部低维表示
   │    │    ├── 16 段 × 2 模态
   │    │    └── 32 段 × 4 模态
   │    ├── 四个关键发射带 Haar 多尺度特征
   │    ├── PCA 几何空间（10 维，门控使用前 5 维）
   │    ├── 同煤种近邻折外残差估计
   │    └── 可靠性门控 + 稳健裁剪 + 0.70 收缩
   │
   └─ 煤种内修正均值守恒
        ↓
      最终批次发热量预测
```

### 关键技术点

1. **批次级光谱表示**：先聚合同一批次的瞬态光谱，使训练样本单位与官方评价单位保持一致，减少弱对齐噪声。
2. **组合预处理**：FFT 高通削弱低频背景，Savitzky–Golay 一阶导数突出局部谱线变化，MSC 校正乘性散射差异。
3. **折内特征选择**：PLS-VIP 仅在相应训练折内计算，筛除大量无效波长并避免验证信息进入特征选择。
4. **多尺度多核 GPR**：不同 SG 窗口和邻域半径描述不同尺度的谱线变化；RBF、Matérn、Rational Quadratic 和 Dot Product 核共同覆盖平滑、粗糙与近线性关系。
5. **C_mad3 稳健校准**：使用训练集折外残差和中位数绝对偏差识别极端样本，再通过煤种内留一法线性拟合校准系统偏差。
6. **几何残差建模**：LVSE 表示局部波段变化，Haar 特征描述发射带的多尺度峰谷与能量，PCA 构建低维样本几何空间。
7. **可靠性门控**：根据测试样本与同煤种训练样本的几何距离估计置信度，对邻域残差进行稳健裁剪和收缩。
8. **煤种内均值守恒**：每个煤种的残差修正均值保持为零，降低二阶段模型破坏基础校准的风险。

**技术说明**

- 最优方案采用 5 折 GroupKFold 生成训练集折外预测，特征选择、基础预测和残差计算均在相应训练范围内完成。
- 代码中的固定常量是最终模型的统一算法配置，包括光谱窗口、核融合比例和残差收缩强度，不包含针对单个测试批次的预测值修补。
- `model/model_config.json` 保存训练规模、折外指标、煤种校准参数和文件哈希；具体固定参数作用见 [fixed_parameters.md](docs/fixed_parameters.md)。
- 固化权重可以准确重建历史提交；面对新的原始光谱时，需要重新执行数据准备、基础模型和最终模型阶段。

## 官方成绩

| 模型阶段 | 官方 RMSE | 说明 |
|---|---:|---|
| GPR + FFT + SG1 + MSC + 煤种校准 | 174.41325 | 早期可靠基线 |
| C_mad3 稳健多核校准 | 143.81585 | 引入稳健筛选与多核融合 |
| 多视图残差共识候选 | 141.41519 | 未超过最终最优方案 |
| 多尺度多核 GPR + 可靠性门控残差修正 | **140.71316** | **最终最优** |
