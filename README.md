# Field LIBS Coal Calorific Value Prediction

基于现场 LIBS 光谱的煤炭弹筒发热量预测方案，记录完整建模过程、官方审核格式代码、固化模型以及比赛平台返回成绩。历史最优官方 RMSE 为 **140.71316**。仓库当前只保留经过独立运行验证的官方审核格式数据驱动版本，历史方案以成绩记录形式保留。

## 项目背景

煤炭发热量是煤质评价、燃料定价和燃烧优化的重要指标。传统弹筒发热量需要在实验室完成取样、混合缩分和化验，检测周期较长。激光诱导击穿光谱（Laser-Induced Breakdown Spectroscopy，LIBS）能够在煤场皮带上快速采集煤流的元素光谱，为发热量在线预测提供基础。

本项目对应“基于现场 LIBS 光谱的煤炭弹筒发热量预测挑战赛”。任务是根据煤场现场采集的 LIBS 光谱以及训练阶段提供的煤质化验信息，预测每个批次的实验室弹筒发热量。训练集包含多个历史月份，测试集为完整的未来月份，因此模型还需要处理真实工业数据中的时间变化。

### 核心难点

1. **多对一弱对齐**：同一批次包含十至二十余条瞬态光谱，却只对应一个混合煤样的宏观化验标签。
2. **高维小样本**：单条光谱包含 7305 个波长通道，而有效训练批次只有 70 个。
3. **现场采集噪声**：煤流状态、击穿位置、基线漂移和散射差异会引入明显的批次内波动。
4. **跨时间分布偏移**：训练集和测试集按月份切分，未来月份的光谱分布可能发生变化。
5. **煤种异质性**：不同煤种的发热量范围、光谱响应和校准关系存在系统差异。

## 方法概述

官方审核版本以批次为基本预测单位，先计算同一批次多条光谱的均值，再对 7 组多尺度表示和 5 类 GPR 核生成 35 个基础分支。核间与尺度间融合权重、正则强度、几何维数和残差修正比例均由训练集折外预测与训练环境验证学习。基础输出经过 C_mad3 煤种校准后，再使用 LVSE、Haar 和 PCA 几何表示进行可靠性门控残差修正。

### 整体架构

```text
同批次 LIBS 光谱（单条 7305 维，多条/批次）
   │
   ├─ 批次级光谱聚合
   │    └── 多条瞬态光谱求均值 → 70 个训练批次 / 26 个测试批次
   │
   ├─ 光谱预处理
   │    ├── FFT 高通去除低频背景
   │    ├── Savitzky–Golay 一阶导数
   │    └── MSC 多元散射校正
   │
   ├─ Stage 1：数据驱动多尺度、多核 GPR
   │    ├── 7 组（SG 窗口，局部邻域半径）
   │    │    └──（5,2）至（17,8），共 7 个尺度
   │    ├── 折内 PLS-VIP 波长选择
   │    ├── 每个尺度建立 5 类 GPR 核
   │    │    ├── RBF
   │    │    ├── Matérn 1.5 / Matérn 2.5
   │    │    ├── Rational Quadratic
   │    │    └── Dot Product
   │    ├── 5 次确定性 VIP 掩码扰动集成
   │    └── 内层验证学习正则、核权重与尺度权重
   │             ↓
   │       35 分支融合基础预测
   │
   ├─ Stage 2：煤种内稳健校准
   │    ├── C_mad3 折外残差异常筛选
   │    └── 煤种内留一法线性校准
   │
   ├─ Stage 3：光谱几何残差修正
   │    ├── 光谱统一重采样至 512 点
   │    ├── LVSE 局部低维表示
   │    ├── 四个关键发射带 Haar 多尺度特征
   │    ├── 训练环境验证选择 PCA 几何维数（最终 10 维）
   │    ├── 同煤种近邻折外残差估计
   │    └── 可靠性门控 + 稳健裁剪 + 训练选择的 0.35 收缩
   │
   ├─ 煤种内修正均值守恒
   │
   └─ 固化训练参数
        ├── VIP 掩码与 GPR 核参数
        ├── 核/尺度融合权重与煤种校准参数
        └── 训练折外残差，不保存预计算测试预测
             ↓
        最终批次发热量预测
```

### 关键技术点

1. **批次级光谱表示**：使训练样本单位与官方评价单位一致，减少瞬态光谱与宏观化验标签之间的弱对齐噪声。
2. **折内特征选择**：PLS-VIP 仅在相应训练折内计算，降低高维光谱噪声和验证偏差。
3. **多尺度多核互补**：7 个局部尺度与 5 类 GPR 核共同覆盖不同宽度的谱线以及平滑、粗糙和近线性关系。
4. **数据驱动融合**：在非负且和为 1 的约束下学习核权重和尺度权重，正则强度由训练集内层验证选择。
5. **多环境稳定性验证**：从时间、主光谱方向和煤种内径向距离构造训练环境，同时参考平均 RMSE 和最差环境 RMSE。
6. **C_mad3 煤种校准**：利用训练折外残差识别异常批次，再执行煤种内稳健线性校准。
7. **几何残差门控**：通过 LVSE、Haar 和 PCA 构造距离空间，根据测试批次的训练支撑度控制残差修正强度。
8. **煤种内均值守恒**：各煤种的残差修正均值保持为零，防止二阶段模型破坏基础预测的整体校准。

**技术说明**

- 候选尺度、核族、正则候选和随机种子在源码顶部统一声明；最终融合权重、GPR 核参数、几何维数和修正比例由训练流程产生。
- `user_data/model_data/model_weights.npz` 采用模型格式 v2，保存训练批次快照、波长轴、VIP 掩码、核参数、融合权重、校准参数和训练残差。
- `test.sh` 会从 `xfdata/` 中重新读取原始训练/测试光谱，在冻结参数下重建 GPR 状态并生成结果，不依赖预计算测试预测。
- 根目录审核版本的参考预测 SHA-256 为 `903637a78e67f5aee3b82fb443a7d6d24e5524f4453fbafa61c018e1ba8a04f8`。
- 历史最优 `140.71316` 作为比赛平台成绩记录保留；仓库根目录的代码、权重和参考结果统一对应当前官方审核格式版本。

## 运行方法

安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

使用固化模型推理：

```bash
bash test.sh
```

从原始数据完整训练：

```bash
bash train.sh
```

验证目录、模型和预测文件：

```bash
python3 code/verify_package.py --xfdata-root xfdata
```

Windows 下可通过 `PYTHON_BIN` 指定 Python；完整说明见 [reproducibility.md](docs/reproducibility.md)。
